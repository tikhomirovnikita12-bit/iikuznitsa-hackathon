# Агент механика

Команды выполняются из корня репозитория. Нужны Python 3.10+, Poppler, Ollama и папка с исходными шестью PDF и ZIP организаторов. По умолчанию это соседняя папка `../007_хакатон_ИИ`. Для другого расположения задайте `MATERIALS_DIR`.

```bash
export MATERIALS_DIR="../007_хакатон_ИИ"
mkdir -p artifacts
unzip -qo "$MATERIALS_DIR"/*mock*.zip -d artifacts
python3 -m venv artifacts/venv
source artifacts/venv/bin/activate
pip install Flask -r artifacts/neuro*/requirements.txt
python -m manual_search.corpus "$MATERIALS_DIR" artifacts/manual-corpus.json
ollama pull gemma2:2b
```

Запустите Ollama и в отдельных терминалах с активированным окружением запустите сервисы.

```bash
uvicorn mock_ml.app:app --app-dir artifacts/neurodvs_hackathon_mock_2026-11-16 --port 8001
uvicorn mock_toir.app:app --app-dir artifacts/neurodvs_hackathon_mock_2026-11-16 --port 8002
python -m agent.server
```

Откройте http://127.0.0.1:8080. Адреса сервисов задают переменные окружения `MOCK_ML_URL`, `MOCK_TOIR_URL`, `OLLAMA_HOST_URL`. Модель задаёт `AGENT_MODEL`. Для автономного чтения диагностики из синтетической карточки есть `AGENT_FIXTURE_MODE=1`.

При запуске с другими адресами скопируйте `agent/.env.example` в `artifacts/agent.env`, измените значения и загрузите их в терминале перед запуском бэкенда.

```bash
set -a
source artifacts/agent.env
set +a
```

## Контракт для команды

- `GET /api/fleet` отдаёт пары ТС и проверок.
- `POST /api/chat` принимает JSON с `vehicle_id`, `session_id`, `question`. Браузер сохраняет cookie. История последних шести реплик и черновики хранятся в памяти процесса отдельно для каждого клиента и случая.
- Ответ содержит `verdict`, `ml_observations` с исходными показателями, `possible_causes`, `risk`, `checks`, `references`, `clarifying_question` и `ticket_draft`. Технический пункт содержит текст и `fragment_id`. Название, PDF-страница и ссылка приходят в `references`.
- Отдельный Flask-стенд предназначен для чтения и проверки диалога. Его `POST /api/confirm` возвращает 409 и не вызывает ТОиР: отправка выполняется в основном экране `run.py` через общий `Workflow` с проверкой качества записи, уверенности, применимости работ, версий и подтверждений.
- Предложенный приоритет задаёт общая серверная логика; подтверждённый приоритет выбирает механик. Список запчастей пуст до установления причины.

## Проверка и стоимость

```bash
PYTHONPATH=. python tests/check_agent.py
python -m agent.benchmark > artifacts/benchmark.json
```

Журнал приложения находится в `artifacts/agent-turns.jsonl`. Каждая строка содержит контекст, вопрос, инструменты и найденные страницы, длительность всей реплики, модель, секунды и счётчики Ollama по каждому обращению. Бенчмарк выполняет три отдельных повтора основного вопроса и один диалог из трёх реплик. Стоимость по тарифу за миллион токенов равна `(input_tokens * input_rate + output_tokens * output_rate) / 1_000_000`. У локального прогона нет оплаты API по токенам.

## Подготовка заявок F08

Проверенный пример общего экрана: `M333YK47 / S-0005`, ЯМЗ-236М2, дизель, `F08`. Раньше агент находил страницы 21, 37 и 78, но отбрасывал их фрагменты, а обработчик превращал отсутствие черновика в 422 с общим диагнозом.

`CaseAgent` использует общий путь для кнопки и команды чата. При наличии пригодных фрагментов сначала работает агент. Если подтверждённая работа не выбрана, берётся существующая операция `Mechanic.suggest_draft()` для пары `engine_model + anomaly_type`: только из проверенной карты, с применимыми ссылками и доступным PDF. Если пригодных фрагментов нет изначально, такая операция готовится без лишнего модельного вызова. Ошибка фактического вызова модели остаётся 503/504.

Для этого F08 используется PDF 16 руководства `236-3902150-Б РЭ`. Операция сохраняет контекст первичного пуска нового двигателя или длительной стоянки. Это условие остаётся в сохранённом черновике и запросе ТОиР. Механик проверяет применимость и подтверждает приоритет; до подтверждения запрос в ТОиР не отправляется. При бензиновом двигателе с F08 (`Y652CK98 / S-0132`) предложение блокируется.

Когда ни проверенной операции, ни пригодных источников нет, экран сохраняет понятное уточнение и `draft_unavailable_reason`; черновик и заявка не создаются. Поздний результат подготовки отбрасывается, если контекст уже изменился.

## Выбор текущего черновика и ответы по руководствам

`TeamWorkflow.current_draft()` выбирает черновик по последней сохранённой диагностике — машине, сессии и коду отклонения. После F02 → F01 открывается новый F01; возврат к F02 восстанавливает его прежний черновик. Старые отправленные и неопределённые заявки остаются в backend-истории и не подменяют карточку текущего кода.

Вопрос «Какое давление масла на прогретом двигателе?» для `A464EP47 / S-0096` использует проверенную выдержку `536.3902150 РЭ`, PDF 49. В одном фрагменте сохранены прогрев 80–100 °C, номинальная частота с 400–635 кПа (4,1–6,5 кгс/см²), минимальный холостой ход с минимумом 100 кПа (1,0 кгс/см²). Уточнение нормы не зависит от ошибочного отнесения вопроса к общему разговору. Новые проверенные выдержки накладываются на уже подготовленный индекс соответствующего руководства.

В выборе ответов одинаковая пара `(fragment_id, текст абзаца)` добавляется один раз, в том числе между разделами. Разные абзацы того же фрагмента остаются доступными.

Проверки: `python -m pytest tests/test_f08_acceptance.py tests/test_diagnosis_draft_switch.py tests/test_manual_agent_answers.py tests/test_draft_flow.py -q`. Они используют настоящие данные, `TeamWorkflow` и исходные ASGI-заглушки; ответы модели управляются тестами. Реальная Gemma и качество новых свободных формулировок требуют отдельного прогона.

## Серверный допуск и конфликты руководств (27.11.2026)

Текущие требования строже исторического сценария F08 выше. Агент использует тот же `backend.admission`, что и маршруты подготовки/подтверждения, и не предлагает произвольную модельную строку как работу заявки. Для F02 ЯМЗ-236 доступен ответ по документации, но нет разрешённого черновика без подтверждённой процедуры контрольного манометра. Для F14 ЗМЗ-40905.10 используется проверка гидронатяжителя PDF 143. F08 требует явного подтверждения первичного пуска/длительной стоянки. Предупреждение качества и приоритет подтверждаются отдельно в основном экране.

Три размеченных конфликта возвращают полный комплект источников без выбора только первой страницы моделью: клапаны РЭ 31 / РК 269, 276; масло РЭ 19 / РК 12; коренные опоры РК 41 / 248. Наблюдения ML отделены от гипотез, оригинальные условия и ограничения сохраняются. Вопрос о фактическом замере или перегоне имеет приоритет над справочным сравнением нормативов.
