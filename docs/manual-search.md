# Поиск по руководствам

## Запуск и проверка

Нужны Python 3.10+ и Poppler (`pdftotext`). Передай путь к каталогу с шестью оригинальными PDF. `artifacts/` создаётся при сборке.

```bash
python3 -m manual_search.corpus "../007_хакатон_ИИ" artifacts/manual-corpus.json
python3 -m manual_search.search artifacts/manual-corpus.json ЯМЗ-236М2 \
  "При каких условиях проверять давление масла?" --fault F02 --limit 1
PYTHONPATH=. python3 tests/check_manual_search.py artifacts/manual-corpus.json
```

Карта файлов и моделей лежит в `data/manuals/catalog.json`. В корпусе есть исходное имя PDF, порядковая страница с единицы, заголовок, текст и модели. ID автоматически извлечённого блока строится из обозначения руководства, страницы и первой строки блока. При смене версии PDF или алгоритма нарезки пересобери индекс. Для вручную сверенных фрагментов ID закреплены в JSON. `continues_from` хранит ID блока с предыдущей страницы.

Явные границы модификаций общего PDF задаются в `data/manuals/zmz-applicability.json`. В остальных блоках при извлечении учитываются явные упоминания модели и номера исполнения. Перечни, подписи к рисункам и таблицы со сносками требуют сверки при добавлении новых эталонов. Заголовки блоков и связи страниц без явной разметки определяются эвристически.

## Стыки с агентом и бэкендом

Участник 4 использует поиск с моделью двигателя из карточки ТС. F01–F14 служат дополнительным контекстом. Для короткого вопроса вроде «Что проверить сначала?» агент может развернуть запрос с учётом текущего случая. Ранжированный результат передаётся агенту как кандидаты для проверки по смыслу. Номер страницы и название для цитаты сервер получает по возвращённому агентом ID.

```python
import json
from pathlib import Path

from manual_search.search import ManualSearch

index = json.loads(Path("artifacts/manual-corpus.json").read_text(encoding="utf-8"))
search = ManualSearch(index)
model = "ЯМЗ-236М2"
hits = search.search("При каких условиях проверять давление масла?", model, "F02")
urls = {"yamz-236-3902150-b-re": "/manuals/yamz-236-3902150-b-re.pdf"}
source = search.resolve_source(hits[0]["fragment_id"], model, urls)
reference = {"manual": source["manual"], "pdf_page": source["pdf_page"]}
```

Участник 2 использует `reference` для ТОиР. `resolve_source()` отклоняет неизвестный ID и фрагмент для другой модификации. Путь в примере предполагает, что приложение уже раздаёт соответствующий исходный PDF. При передаче URL сервер формирует ссылку вида `/manuals/...pdf#page=19`.

| Кейс | Вопрос | Ожидаемый ID |
|---|---|---|
| `E549YT198 / S-0011`, ЯМЗ-236М2, F02 | При каких условиях проверять давление масла? | `yamz-236-3902150-b-re-p019-oil-pressure` |
| `E549YT198 / S-0011`, ЯМЗ-236М2, F02 | Какие причины пониженного давления указаны в руководстве? | `yamz-236-3902150-b-re-p053-low-oil-pressure` |
| `Y815BM178 / S-0152`, ЗМЗ-40905.10, F14 | Что вызывает равномерный шум спереди на средних оборотах? | `zmz-40904-40905-rk-p107-engine-knock` |

## Приёмка с участником 5

В [наборе из 15 вопросов](../tests/manual-search-cases.json) у каждого есть ожидаемый ответ или уточнение. У 13 проверяются попадания поиска, у Q13 и Q15 требуется диалог с агентом. В Q01–Q03 проверь, что ссылки из чата открывают порядковые страницы 19 и 53 на смартфоне. На 19-й должен быть виден пункт 2 «Контроль за работой», на 53-й — таблица «Пониженное давление масла в системе смазки». Для Q11–Q12 на стр. 107 должны быть видны строки про гидронатяжитель и удлинение цепи. У Q09–Q10 один вопрос про ДМРВ задаётся для двух модификаций.

Первый локальный прогон Q01 поднял стр. 132 выше 19-й. Исправление добавило предметные формулировки к сверенной выдержке. Повторный прогон проходит все 13 поисковых проверок. В корпусе 1743 страницы источников, 40 пометок о пустом или скудном текстовом слое. Контактные листы показали обложки, чертежи и несколько таблиц, преимущественно в РК ЯМЗ-236. Например, PDF 144, 271–273, 277–278 и 280 содержат таблицы, которые требуют OCR или ручной разметки для поиска по их содержимому. Страницы контрольных вопросов доступны.

Переход по ссылке из чата, подтверждение участником 5 и обработка уточнений проверяются на собранном приложении.
