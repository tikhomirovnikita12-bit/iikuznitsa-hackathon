# Языки интерфейса и чата

В шапке доступны русский, белорусский, азербайджанский, казахский, кыргызский, туркменский, узбекский, армянский, таджикский и хинди. Выбор сохраняется в браузере и задаёт язык интерфейса. При ручном вводе агент отвечает на языке вопроса. Язык интерфейса используется, когда короткий или смешанный текст невозможно уверенно распознать, и для встроенных действий. Подписи диагностики, истории, парка, черновика и страницы источника загружаются из локальных словарей без подключения к облаку. Исходные PDF, цитаты, номера машин и заявок открываются в исходном виде. Уже отправленные сообщения хранятся с языком своего ответа.

Словари интерфейса лежат в `web/locales/`. Ключ — русский текст интерфейса, значение — перевод. В динамических подписях сохраняйте подстановки в фигурных скобках. Для новых текстов за пределами словаря используется исходный текст. Основные подписи вычитаны вручную, остальные переводы получены локальной моделью NLLB-200 и требуют языковой вычитки. [Карточка модели NLLB-200](https://huggingface.co/facebook/nllb-200-distilled-600M)

## Два сценария для демо

Выберите ТС и сессию, дождитесь диагностики, выберите язык и нажмите «Задать демо-вопрос». В каждом сценарии вопрос можно отправить и из поля ввода. Облачная учётная запись для этих сценариев не нужна.

| ТС и сессия | Вопрос | Что сверить |
| --- | --- | --- |
| `E549YT198 / S-0011`, ЯМЗ-236М2, F02 | Какое давление масла должно быть на прогретом двигателе? | Условие прогрева, 400–700 кПа при 2100 об/мин, минимум 100 кПа на минимальном холостом ходу. Пределы после длительной эксплуатации отдельно. Цитата и [PDF 19](http://127.0.0.1:8000/sources/yamz236-re/19) |
| `Y815BM178 / S-0152`, ЗМЗ-40905.10, F14 | Когда менять гидронатяжитель ГРМ с адаптером? | Промежуточное положение плунжера после снятия как условие замены. Размер 55,5 ± 0,5 мм относится к полностью выдвинутому плунжеру детали `40904.1006100`. Цитата и [PDF 146](http://127.0.0.1:8000/sources/zmz409/146) |

В [демо-текстах](../data/manuals/demo-locales.json) и [глоссарии](../data/manuals/translation-glossary.csv) сохранены рабочие переводы. Перед защитой попросите человека, владеющего каждым выбранным языком и терминологией ДВС, сверить смысл. Автотесты проверяют два сценария для всех десяти языков, числа, код двигателя, артикул и точную ссылку. Лингвистическую вычитку они не заменяют.

## Произвольные вопросы

Для локального демо можно запустить переводчик с CTranslate2, SentencePiece и fastText. Нужны совместимая копия NLLB-200 для CTranslate2 с `sentencepiece.bpe.model` и модель определения языка `lid.176.ftz`. Модели хранятся отдельно от репозитория. [Модель определения языка](https://fasttext.cc/docs/en/language-identification.html) · [Карточка NLLB-200](https://huggingface.co/facebook/nllb-200-distilled-600M)

```bash
python -m pip install ctranslate2 sentencepiece fasttext-community
python scripts/local_translation.py --model /path/to/model --detector /path/to/lid.176.ftz
```

В окружении стенда задайте `LOCAL_TRANSLATION_URL=http://127.0.0.1:18191`. При настроенном Google Cloud используется облачный перевод с глоссарием. Локальный переводчик сохраняет значения и подставляет терминологию из CSV.

Включите Cloud Translation API в проекте Google Cloud. Загрузите CSV глоссария в Cloud Storage и создайте **equivalent terms glossary** в `us-central1` с языками `ru,be,az,kk,ky,tk,uz,hy,tg,hi`. Для локального запуска настройте Application Default Credentials и укажите `GOOGLE_TRANSLATION_PROJECT` и `GOOGLE_TRANSLATION_GLOSSARY` (ID глоссария). Для произвольных технических вопросов запустите стенд с `python run.py --agent` и настроенной Ollama. В Docker передайте credentials через окружение исполнения или подключите файл ADC отдельным read-only volume и укажите его путь внутри контейнера в `GOOGLE_APPLICATION_CREDENTIALS`. [Настройка глоссария](https://docs.cloud.google.com/translate/docs/advanced/glossary) · [Аутентификация](https://docs.cloud.google.com/translate/docs/authentication)

Вопрос переводится на русский до вызова агента. В ответе переводится отображаемый текст, а ссылки и содержимое черновика заявки берутся из русскоязычного результата. Числа, известные единицы, модель двигателя и артикулы восстанавливаются из исходного текста. Секции с источниками доступны и на русском. При ошибке перевода иностранного вопроса чат сохраняет текст в поле ввода. При ошибке на выходе чат показывает исходный русский ответ и сообщает об ошибке перевода. В `POST /api/chat` режим `match_input_language: true` определяет язык ответа по тексту вопроса, а `language` задаёт запасной вариант. Встроенные действия передают исходный русский текст через `input_language: "ru"`. Для отредактированного текста снова включается определение языка.
