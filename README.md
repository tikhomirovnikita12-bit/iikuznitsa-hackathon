# iikuznitsa-hackathon
Командный проект для хакатона ИИкузница.

[Поиск по руководствам и приёмка](docs/manual-search.md)

Локальный запуск после установки зависимостей — `.venv/bin/python main.py`. Рабочий стол механика откроется по адресу [http://127.0.0.1:8000/](http://127.0.0.1:8000/).
