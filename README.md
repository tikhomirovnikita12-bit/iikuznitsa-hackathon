## Интегрированный экран и приёмка

Локальный стенд использует командный бэкенд, поиск по руководствам и исходные Mock ML и Mock ТОиР. Кнопка «Состояние парка» открывает сводку с фильтрами, оценками пяти проверок и переходом к сессии. После диагностики доступна история проверок машины.

Нужны Python 3.13, Poppler с `pdftotext` и `pdftoppm` в PATH и выданный заказчиком архив `007_хакатон_ИИ.zip`. Для чистого клона в PowerShell выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m mechanic.prepare "C:\материалы\007_хакатон_ИИ.zip"
.\.venv\Scripts\python.exe run.py
```

Откройте [интегрированный экран](http://127.0.0.1:8000/). Подготовка раскладывает PDF и заглушки по папкам внутри `artifacts`, строит индекс шести PDF и создаёт изображения контрольных страниц. При уже распакованных материалах можно запустить `python -m mechanic.prepare` без аргумента.

- `run.py` запускает экран и заглушки. Чат работает в тестовом режиме, а работы и ссылки для черновика берутся из командного `Workflow`.
- `run.py --agent` подключает к экрану командного агента. Запустите Ollama и подготовьте модель командой `ollama pull gemma2:2b`. Адрес сервиса и модель можно настроить через `OLLAMA_URL` и `OLLAMA_MODEL`.
- `main.py` запускает отдельно API и заглушки. [Swagger UI](http://127.0.0.1:8000/docs)

SQLite, материалы заказчика и производные файлы находятся в игнорируемом каталоге `artifacts`. Схема настроек есть в `.env.example`.

Полный локальный прогон `.\.venv\Scripts\python.exe scripts/selftest.py` запускает Python-тесты, проверку синтаксиса `web/app.js`, 13 поисковых кейсов и 17 браузерных проверок. Флаги `--skip-browser` и `--skip-search` позволяют ускорить повторный прогон. Команда `.\.venv\Scripts\python.exe scripts/cleanroom_check.py` копирует исходники без артефактов, строит корпус из архива заказчика и повторяет прогон.
