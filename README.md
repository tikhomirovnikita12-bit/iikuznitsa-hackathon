## Интегрированный экран и приёмка

Локальный стенд использует командный бэкенд, поиск по руководствам и исходные Mock ML и Mock ТОиР. Чат и текст черновика обозначены как тестовые до подключения агента участника 4.

Нужны Python 3.13, Poppler с `pdftotext` и `pdftoppm` в PATH и выданный заказчиком архив `007_хакатон_ИИ.zip`. Для чистого клона в PowerShell выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m mechanic.prepare "C:\материалы\007_хакатон_ИИ.zip"
.\.venv\Scripts\python.exe run.py
```

Откройте [интегрированный экран](http://127.0.0.1:8000/). Подготовка раскладывает PDF и заглушки по папкам внутри `artifacts`, строит индекс шести PDF и создаёт изображения контрольных страниц. При уже распакованных материалах можно запустить `python -m mechanic.prepare` без аргумента. `run.py` запускает экран на порту 8000, Mock ML на 8001 и Mock ТОиР на 8002. Для повторного запуска достаточно `run.py`. Для отдельного запуска API и заглушек используйте `python main.py` из виртуального окружения. [Swagger UI](http://127.0.0.1:8000/docs).

SQLite, материалы заказчика и производные файлы находятся в игнорируемом каталоге `artifacts`. Схема настроек есть в `.env.example`.
